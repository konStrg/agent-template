# Copilot Agents Identity Card — Java / Spring Boot / Maven Project

This file describes the native Copilot multi-agent organization used in
this project. It serves as a global entry point before consulting the
detailed definitions in `.github/agents/`. Each agent listed below is also
a **native Copilot CLI agent** selectable via `copilot --agent <name>`
or `/agent <name>` in a session.

## Main agent

| Agent | Role | File |
|---|---|---|
| **Orchestrator** | Meta-agent, drives the workflow and routes tasks | `.github/agents/orchestrator.agent.md` |

## Sub-agents

| Agent | Role | File |
|---|---|---|
| **Architect** | Technical design, specs, DTOs, contracts | `.github/agents/architect.agent.md` |
| **Test** (QA) | Writing unit/integration tests (TDD, RED phase) | `.github/agents/test.agent.md` |
| **Dev** | Implementation of production code (GREEN phase) | `.github/agents/dev.agent.md` |
| **Reviewer** | Review of quality, security, compliance with rules | `.github/agents/reviewer.agent.md` |

## Workflow

0. **Architect** (called separately, outside the Orchestrator) produces the
   specifications and contracts in `docs/specs/`. The Orchestrator receives
   this spec as input.
1. **Test** writes the tests in `src/test/java/` and validates the **RED**
   status (`mvn test` must fail).
2. **Dev** implements the minimal code in `src/main/java/` and validates the
   **GREEN** status (`mvn test` must pass).
3. **Reviewer** validates quality, security and compliance with the rules
   defined in `.github/instructions/`, including proper code placement
   (`project-structure.instructions.md`).

## Architecture

`ARCHITECTURE.md` (at the root) documents the application overview and its
multi-repo mapping. It must be consulted before any design work and updated
by the Architect on any structural change.

## Strict TDD reminder

> No line of production code must be written before the corresponding test
> exists and fails (RED). Production code is only written to make the tests
> pass (GREEN), without anticipating untested functionality.

For any build/test action, use the skills in `.github/skills/` (notably
`maven-build` and `oracle-tester`).

## Alignment with native Copilot CLI

This organization is 100% aligned with the native locations recognized by
Copilot CLI:

| Item | Native location |
|---|---|
| Global instructions | `.github/copilot-instructions.md` |
| Custom agents | `.github/agents/*.agent.md` |
| Skills | `.github/skills/<name>/SKILL.md` |
| Path-specific instructions | `.github/instructions/*.instructions.md` |
| Hooks | `.github/hooks/*.json` |
| MCP configuration | `.github/mcp.json` |
| Repo settings | `.github/copilot/settings.json` |
