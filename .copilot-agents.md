# Carte d'identité des agents Copilot — Projet Java / Spring Boot / Maven

Ce fichier décrit l'organisation multi-agents native Copilot utilisée sur ce
projet. Il sert de point d'entrée global avant de consulter les définitions
détaillées dans `.github/agents/`. Chaque agent listé ci-dessous est aussi
un **agent natif Copilot CLI** sélectionnable via `copilot --agent <nom>`
ou `/agent <nom>` en session.

## Agent principal

| Agent | Rôle | Fichier |
|---|---|---|
| **Orchestrator** | Meta-agent, pilote le workflow et route les tâches | `.github/agents/orchestrator.agent.md` |

## Sous-agents

| Agent | Rôle | Fichier |
|---|---|---|
| **Architect** | Conception technique, specs, DTOs, contrats | `.github/agents/architect.agent.md` |
| **Test** (QA) | Rédaction des tests unitaires/intégration (TDD, phase ROUGE) | `.github/agents/test.agent.md` |
| **Dev** | Implémentation du code de production (phase VERTE) | `.github/agents/dev.agent.md` |
| **Reviewer** | Revue qualité, sécurité, conformité aux règles | `.github/agents/reviewer.agent.md` |

## Workflow

1. **Architect** produit les spécifications et contrats dans `docs/specs/`.
2. **Test** écrit les tests dans `src/test/java/` et valide le statut **ROUGE**
   (`mvn test` doit échouer).
3. **Dev** implémente le code minimal dans `src/main/java/` et valide le
   statut **VERT** (`mvn test` doit passer).
4. **Reviewer** valide la qualité, la sécurité et le respect des règles
   définies dans `.github/instructions/`, y compris le bon placement du
   code (`project-structure.instructions.md`).

## Architecture

`ARCHITECTURE.md` (à la racine) documente la vue d'ensemble de
l'application et sa cartographie multi-repo. Il doit être consulté avant
toute conception et mis à jour par l'Architecte en cas d'évolution
structurelle.

## Rappel TDD strict

> Aucune ligne de code de production ne doit être écrite avant que le test
> correspondant n'existe et n'échoue (ROUGE). Le code de production n'est
> écrit que pour faire passer les tests au VERT, sans anticipation de
> fonctionnalités non testées.

Pour toute action de build/test, utiliser les compétences de
`.github/skills/` (notamment `maven-build` et `oracle-tester`).

## Alignement avec Copilot CLI natif

Cette organisation est 100% alignée avec les emplacements natifs reconnus
par Copilot CLI :

| Élément | Emplacement natif |
|---|---|
| Instructions globales | `.github/copilot-instructions.md` |
| Agents custom | `.github/agents/*.agent.md` |
| Compétences (skills) | `.github/skills/<nom>/SKILL.md` |
| Instructions path-specific | `.github/instructions/*.instructions.md` |
| Hooks | `.github/hooks/*.json` |
| Configuration MCP | `.github/mcp.json` |
| Réglages repo | `.github/copilot/settings.json` |
